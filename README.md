## 💻 Automation Projects

### [JML PowerShell Lifecycle Automation](https://github.com/nigel-kendrick/jml-powershell-lifecycle)

Automated Joiner/Mover/Leaver (JML) identity lifecycle management demonstrating **Identity Governance & Administration (IGA)** concepts used in enterprise tools like SailPoint and Saviynt.

**Key Features:**
- **Joiner Workflow** - Automated provisioning from HR feed to AD/Entra ID with group-based licensing
- **Mover Workflow** - Department transfers with automatic group updates and manager changes
- **Leaver Workflow** - Secure offboarding with account disable, group removal, password scrambling, and dual AD/Entra ID deactivation

**Technologies:** PowerShell, Active Directory, Microsoft Graph API, Azure Entra ID

**IGA Concepts:** Authoritative source integration, birthright provisioning, role-based access control, separation of duties, audit logging
